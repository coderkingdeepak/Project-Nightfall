# Project Nightfall

A C++ tactical stealth and extraction gameplay project focused on advanced gameplay systems, pathfinding, enemy behavior, and mission progression.

## Overview

Project Nightfall is a Phase 4 project in my AAA Gameplay Engineer learning roadmap. Its tactical stealth and extraction scenario brings together advanced gameplay concepts involving navigation, enemy detection, combat, and mission objectives.

## Core Gameplay Scenario

Navigate a tactical environment, avoid or respond to enemy detection, use enemy behavior and navigation systems, and complete the extraction objective.

## Core Systems

- Advanced Gameplay Systems
- A* Pathfinding Algorithm
- Grid-Based Pathfinding
- Line-of-Sight (LOS) Checks
- Enemy Patrol
- Enemy Detection
- Enemy Chase Behavior
- Combat System
- Extraction System
- Mission States

## Technologies

- C++
- Visual Studio

## Engineering Focus

This project explores the integration of navigation algorithms, enemy AI states, visibility checks, combat mechanics, and mission progression into a unified gameplay architecture.
